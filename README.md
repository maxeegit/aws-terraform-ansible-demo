# AWS Terraform & Ansible — Cloud DevOps & Security Demo

A hands-on AWS DevOps project demonstrating **Infrastructure as Code, configuration management, containerization, CI/CD, Kubernetes, cloud security, and observability**.

## 🛠️ Technologies

**AWS:** EC2, VPC, IAM, ECR, SSM, CloudWatch, CloudTrail, KMS, GuardDuty, Security Hub, AWS Config
**IaC & Automation:** Terraform, Ansible, Python, Bash
**Containers:** Docker, Kubernetes, Kind
**CI/CD:** GitHub Actions, GitHub OIDC
**Security:** Trivy, Checkov, IAM least privilege, encryption, security groups
**Observability:** Prometheus, Grafana, CloudWatch, Datadog

## 🚀 What I Implemented

* Provisioned AWS infrastructure using **Terraform**
* Automated server configuration with **Ansible and AWS Systems Manager**
* Built and deployed containerized applications using **Docker and Amazon ECR**
* Implemented **GitHub Actions CI/CD** with automated validation and deployment
* Configured **GitHub OIDC with AWS IAM** to eliminate long-lived cloud credentials
* Applied security controls using **IAM, KMS, GuardDuty, Security Hub and AWS Config**
* Integrated **Trivy and Checkov** for container and Infrastructure-as-Code security scanning
* Implemented **Prometheus/Grafana and CloudWatch** monitoring
* Applied cloud security practices including least privilege, encryption, logging and network controls
